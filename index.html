لینوکس مقدماتی رایگان

از صفر با ترموکس و خط فرمان آشنا شو تا آماده نوشتن اولین بات بشی.

فصل ۱ — آشنایی با لینوکس و Termux 3 درس
✓ لینوکس چیه و چرا برای بات‌سازی لازمشه؟ +

لینوکس یه سیستم‌عامل متن‌بازه که اکثر سرورهای دنیا (و از جمله سرورهایی که بات‌های تلگرام روشون اجرا می‌شن) روی اون کار می‌کنن. برخلاف ویندوز که بیشتر با کلیک و ماوس کار می‌کنی، توی لینوکس اکثر کارها با تایپ دستور توی یه پنجره به اسم «ترمینال» انجام می‌شه. یاد گرفتن لینوکس یعنی یاد گرفتن زبان مشترک تقریباً همه‌ی سرورها و ابزارهای برنامه‌نویسی — و چون گوشی اندروید هم هسته‌ش لینوکسه، می‌تونیم بدون هیچ سروری، مستقیم روی گوشی یه محیط لینوکسی کامل داشته باشیم.

✓ نصب Termux روی اندروید +

Termux یه اپلیکیشن رایگانه که یه محیط لینوکسی کامل رو داخل گوشی اندرویدت شبیه‌سازی می‌کنه، بدون نیاز به روت کردن گوشی. بهترین راه نصب، دانلود از F-Droid یا مستقیم از گیت‌هاب پروژه‌ست (نسخه‌ی گوگل‌پلی قدیمی و به‌روزرسانی نشده‌ست). بعد از نصب و باز کردن اپ، اولین کاری که باید بکنی به‌روزرسانی لیست پکیج‌هاست:

pkg update && pkg upgrade -y
✓ اولین دستورات: ls، cd، pwd +

سه تا دستور پایه که همیشه ازشون استفاده می‌کنی: pwd مسیر فعلی‌ای که توش هستی رو نشون می‌ده، ls محتوای همون پوشه رو لیست می‌کنه، و cd به پوشه‌ی دیگه‌ای می‌ره. مثلاً:

pwd
ls
cd storage/downloads
ls -la   # نمایش فایل‌های مخفی هم
فصل ۲ — دستورات پایه ترمینال 3 درس
✓ ساخت، کپی و حذف فایل و پوشه +

برای کار روزمره با فایل‌ها چهار دستور کلیدی کافیه: mkdir برای ساخت پوشه، touch برای ساخت فایل خالی، cp برای کپی، و rm برای حذف. با پرچم -r می‌تونی این کارها رو روی پوشه‌ها (و محتویاتشون) هم انجام بدی.

mkdir my_bot
touch my_bot/bot.py
cp my_bot/bot.py my_bot/bot_backup.py
rm my_bot/bot_backup.py
rm -r my_bot   # حذف کل پوشه، با احتیاط!
✓ نصب برنامه با pkg +

Termux از مدیر پکیج خودش به اسم pkg استفاده می‌کنه که در واقع روی apt (همون سیستم دبیان/اوبونتو) نشسته. برای نصب هر ابزاری کافیه بنویسی pkg install اسم‌ابزار. مثلاً برای نصب گیت:

pkg install git -y
pkg list-installed   # دیدن چی نصب کردی
✓ ویرایشگر متن nano +

nano یه ویرایشگر متن ساده و سبکه که مستقیم توی ترمینال کار می‌کنه — برای شروع خیلی راحت‌تر از vim یا emacs هست. با nano اسم‌فایل بازش می‌کنی، متن رو می‌نویسی، و با Ctrl+O ذخیره و Ctrl+X خارج می‌شی.

فصل ۳ — مدیریت فایل و پوشه پیشرفته‌تر 2 درس
✓ مسیرهای مطلق و نسبی +

مسیر مطلق از ریشه‌ی سیستم شروع می‌شه (مثلاً /data/data/com.termux/files/home) و همیشه یکسانه، فارغ از اینکه الان کجا هستی. مسیر نسبی به موقعیت فعلیت بستگی داره؛ مثلاً ../ یعنی برو یه پوشه بالاتر. دونستن این تفاوت باعث می‌شه اسکریپت‌هات روی هر دستگاهی درست کار کنن.

✓ دسترسی به حافظه گوشی +

برای اینکه Termux به پوشه‌ی Download و بقیه‌ی حافظه‌ی گوشیت دسترسی داشته باشه، باید یه بار این دستور رو بزنی و اجازه‌ی دسترسی به فایل‌ها رو بدی:

termux-setup-storage
فصل ۴ — آماده‌سازی محیط برای بات‌نویسی 2 درس
✓ نصب پایتون و pip +

پایتون رو با یک خط دستور نصب می‌کنیم؛ pip هم به‌صورت خودکار همراهش نصب می‌شه و برای نصب کتابخونه‌های پایتون ازش استفاده خواهیم کرد.

pkg install python -y
python --version
pip --version
✓ نصب یک ویرایشگر کد (اختیاری) +

می‌تونی همون nano رو برای نوشتن کدهای کوتاه استفاده کنی، یا اپ‌هایی مثل Acode رو نصب کنی که هایلایت رنگی کد و امکانات بیشتری دارن و مستقیم با پوشه‌ی Termux هم هماهنگ می‌شن.

فصل ۵ — مدیریت پکیج‌ها و مخازن 2 درس
✓ جست‌وجو و حذف پکیج +

برای پیدا کردن اسم دقیق یه پکیج از pkg search استفاده می‌کنی، و برای حذف یه برنامه‌ی نصب‌شده از pkg uninstall.

pkg search ffmpeg
pkg uninstall ffmpeg -y
✓ به‌روزرسانی خودکار مخازن +

هر از گاهی لیست مخازن Termux تغییر می‌کنه (مثلاً آدرس سرورها عوض می‌شه). دستور termux-change-repo بهت اجازه می‌ده سریع‌ترین مخزن رو انتخاب کنی و مشکلات دانلود کند رو حل کنی.

فصل ۶ — متغیرهای محیطی و PATH 2 درس
✓ متغیر محیطی چیست؟ +

متغیر محیطی مقداریه که سیستم‌عامل و برنامه‌ها می‌تونن بهش دسترسی داشته باشن، مثل مسیر پوشه‌ی خانگی یا زبان سیستم. با echo $HOME می‌تونی مقدار یه متغیر رو ببینی.

echo $HOME
export MY_NAME="Ali"
echo $MY_NAME
✓ PATH چیست و چرا مهمه؟ +

PATH لیستی از پوشه‌هاست که سیستم توشون دنبال برنامه‌ی اجرایی می‌گرده. وقتی می‌نویسی python، سیستم توی همه‌ی پوشه‌های داخل PATH دنبال فایل اجرایی python می‌گرده تا پیداش کنه.

فصل ۷ — لوله‌ها و ریدایرکت‌ها 2 درس
✓ ریدایرکت خروجی با > و >> +

با > می‌تونی خروجی یه دستور رو به‌جای نمایش روی صفحه، توی یه فایل ذخیره کنی؛ >> هم همین کارو می‌کنه ولی به‌جای بازنویسی، به انتهای فایل اضافه می‌کنه.

echo "سلام" > note.txt
echo "خط دوم" >> note.txt
cat note.txt
✓ لوله (pipe) با | +

علامت | خروجی یه دستور رو مستقیم به‌عنوان ورودی دستور بعدی می‌فرسته. این یکی از قدرتمندترین ایده‌های خط فرمان لینوکسه چون بهت اجازه می‌ده چند دستور ساده رو زنجیر کنی.

ls -la | grep ".py"

پایتون صفر تا صد رایگان

از اولین خط کد تا ساخت بات تلگرام واقعی با کتابخونه‌ی python-telegram-bot.

فصل ۱ — شروع کار 2 درس
✓ اولین برنامه: Hello World +

سنت هر زبان برنامه‌نویسی اینه که اولین برنامه، یه پیام ساده چاپ کنه. توی پایتون این کار با تابع print() انجام می‌شه:

🐍 Python
✓ اجرای فایل پایتون +

کد رو توی فایلی با پسوند py. ذخیره کن (مثلاً hello.py) و توی ترمینال با این دستور اجراش کن:

python hello.py
فصل ۲ — متغیرها و انواع داده 2 درس
✓ متغیر چیست؟ +

متغیر یه اسمه که به یه مقدار توی حافظه اشاره می‌کنه. توی پایتون لازم نیست نوع متغیر رو از قبل مشخص کنی؛ خودش تشخیص می‌ده.

🐍 Python
✓ رشته، عدد و بولین +

سه نوع داده‌ی پرکاربرد: str برای متن (بین گیومه)، int/float برای عدد صحیح و اعشاری، و bool که فقط True یا False می‌گیره. تابع type() نوع هر متغیر رو بهت نشون می‌ده.

فصل ۳ — شرط و حلقه 2 درس
✓ دستور شرطی if / elif / else +

با if می‌تونی بگی «اگه فلان شرط برقرار بود، این کارو بکن». elif یعنی «وگرنه اگه»، و else یعنی «در غیر این صورت».

🐍 Python
✓ حلقه‌های for و while +

حلقه برای تکرار یه کار استفاده می‌شه. for روی یه دنباله (مثل لیست یا بازه‌ی اعداد) پیمایش می‌کنه، while تا وقتی شرطی برقراره تکرار می‌شه.

🐍 Python
فصل ۴ — توابع و ماژول‌ها 2 درس
✓ نوشتن تابع با def +

تابع یه بلوک کد قابل‌استفاده‌ی مجدده. با def تعریفش می‌کنی و با return مقدار خروجی رو برمی‌گردونی.

🐍 Python
✓ وارد کردن ماژول‌ها با import +

پایتون کتابخونه‌های آماده‌ی زیادی داره. با import می‌تونی ازشون توی برنامه‌ت استفاده کنی، مثلاً ماژول random برای تولید عدد تصادفی.

فصل ۵ — ساخت اولین بات تلگرام 3 درس
✓ نصب python-telegram-bot +

این کتابخونه محبوب‌ترین ابزار پایتونی برای ساخت بات تلگرامه. نصبش با pip خیلی ساده‌ست:

pip install python-telegram-bot --upgrade
✓ گرفتن توکن از BotFather +

برای ساخت بات باید با اکانت @BotFather توی تلگرام چت کنی، دستور /newbot رو بزنی، یه اسم و یوزرنیم انتخاب کنی، و در نهایت یه توکن مخصوص بات خودت بگیری. این توکن رو هیچ‌وقت جایی عمومی منتشر نکن.

✓ نوشتن دستور /start +

با چند خط کد می‌تونی اولین دستور بات رو بسازی که به /start جواب بده:

from telegram.ext import Application, CommandHandler

async def start(update, context):
    await update.message.reply_text("سلام! من فعالم 🤖")

app = Application.builder().token("TOKEN_خودت").build()
app.add_handler(CommandHandler("start", start))
app.run_polling()
فصل ۶ — لیست، دیکشنری و ساختارهای داده 2 درس
✓ کار با لیست‌ها +

لیست یه مجموعه‌ی مرتب از مقادیره که می‌تونی بهش اضافه کنی، ازش حذف کنی و با اندیس بهش دسترسی داشته باشی.

🐍 Python
✓ کار با دیکشنری +

دیکشنری داده رو به‌صورت کلید-مقدار نگه می‌داره؛ برای ذخیره‌ی اطلاعات کاربرهای بات (مثل شناسه و سهمیه) خیلی کاربردیه.

🐍 Python
فصل ۷ — کار با فایل و ذخیره‌سازی داده 2 درس
✓ خواندن و نوشتن فایل متنی +

با تابع open می‌تونی فایل رو باز کنی. استفاده از with باعث می‌شه فایل بعد از کار خودکار بسته بشه.

with open("users.txt", "a") as f:
    f.write("کاربر جدید\n")

with open("users.txt") as f:
    print(f.read())
✓ ذخیره‌ی داده‌ی ساخت‌یافته با JSON +

برای ذخیره‌ی دیکشنری یا لیست به شکل قابل‌خوندن و بازیابی، از ماژول json استفاده می‌کنیم. این روش برای نگه‌داشتن اطلاعات کاربرهای بات بین اجراهای مختلف خیلی رایجه.

import json
data = {"users": ["علی", "سارا"]}
with open("data.json", "w") as f:
    json.dump(data, f, ensure_ascii=False)
فصل ۸ — مدیریت خطا و اشکال‌زدایی 2 درس
✓ گرفتن خطا با try/except +

وقتی احتمال داره یه بخش از کد خطا بده (مثلاً کاربر عدد وارد نکنه)، با try/except می‌تونی جلوی کرش کردن کل برنامه رو بگیری.

try:
    age = int(input("سنت چنده؟ "))
except ValueError:
    print("لطفاً فقط عدد وارد کن")
✓ چاپ خطا برای دیباگ +

موقع توسعه‌ی بات، خوندن پیام خطای کامل (traceback) کمک می‌کنه بفهمی دقیقاً کجای کد مشکل داره. هیچ‌وقت خطاها رو کامل قایم نکن؛ حداقل توی لاگ چاپشون کن.

HTML از صفر رایگان

ساختار وب رو یاد بگیر: تگ‌ها، فرم‌ها و صفحه‌ی اول خودت.

فصل ۱ — ساختار پایه یک صفحه 2 درس
✓ اسکلت اصلی HTML +

هر صفحه‌ی HTML با یه ساختار ثابت شروع می‌شه: doctype، تگ html، head برای اطلاعات پشت‌صحنه، و body برای محتوایی که کاربر می‌بینه.

<!DOCTYPE html>
<html>
<head>
  <title>صفحه من</title>
</head>
<body>
  <h1>سلام دنیا</h1>
</body>
</html>
✓ تگ‌های سرتیتر و پاراگراف +

از h1 تا h6 برای تیترها (h1 بزرگ‌ترین) و p برای پاراگراف متن استفاده می‌شه.

فصل ۲ — تگ‌های پرکاربرد 2 درس
✓ لینک و تصویر +

تگ a برای ساخت لینک و img برای نمایش تصویره. هر دو از ویژگی‌هایی مثل href و src استفاده می‌کنن که مقصد یا منبع رو مشخص می‌کنن.

<a href="https://example.com">برو به سایت</a>
<img src="pic.jpg" alt="توضیح تصویر">
✓ لیست‌ها و جدول‌ها +

ul برای لیست بدون شماره و ol برای لیست شماره‌دار به کار می‌ره، هر آیتم داخل li قرار می‌گیره. جدول‌ها هم با table، tr (سطر) و td (ستون) ساخته می‌شن.

فصل ۳ — فرم‌ها 1 درس
✓ ساخت فرم و input +

تگ form محل قرارگیری فیلدهای ورودیه. تگ input انواع مختلفی داره: text، email، password، checkbox و ...

<form>
  <input type="text" placeholder="نام">
  <input type="email" placeholder="ایمیل">
  <button type="submit">ارسال</button>
</form>
فصل ۴ — معنایی‌سازی صفحه (Semantic HTML) 1 درس
✓ چرا فقط div کافی نیست؟ +

تگ‌های معنایی مثل header، nav، main، section و footer به مرورگر و موتورهای جست‌وجو می‌گن هر بخش از صفحه چه نقشی داره؛ این هم برای SEO خوبه و هم صفحه رو برای صفحه‌خوان‌های نابینایان قابل‌فهم‌تر می‌کنه.

<header>...</header>
<nav>...</nav>
<main>
  <section>...</section>
</main>
<footer>...</footer>
فصل ۵ — اتصال HTML به CSS و JavaScript 1 درس
✓ لینک کردن فایل CSS و JS خارجی +

برای یه پروژه‌ی واقعی، بهتره CSS و JS رو توی فایل جدا بنویسی و با تگ link و script بهشون وصل بشی؛ این کار کد رو تمیزتر و قابل‌نگهداری‌تر می‌کنه.

<link rel="stylesheet" href="style.css">

CSS از صفر رایگان

رنگ، فاصله‌گذاری، فلکس‌باکس و گرید — طراحی صفحه‌ی خودت رو یاد بگیر.

فصل ۱ — مقدمات استایل‌دهی 2 درس
✓ سه روش نوشتن CSS +

می‌تونی استایل رو inline (داخل خود تگ)، internal (داخل تگ style توی head) یا external (فایل جدای css.) بنویسی. روش external برای پروژه‌های واقعی بهترینه چون کد رو تمیز نگه می‌داره.

✓ سلکتورها +

سلکتور مشخص می‌کنه استایل روی کدوم عنصر اعمال بشه: با تگ (p)، با کلاس (.title.) یا با آیدی (#header.).

p { color: gray; }
.title { font-weight: bold; }
#header { background: black; }
فصل ۲ — باکس مدل 1 درس
✓ margin، padding و border +

هر عنصر HTML مثل یه جعبه‌ست: padding فاصله‌ی داخلی بین محتوا و لبه‌ست، border خط دور جعبه‌ست، و margin فاصله‌ی بیرون جعبه با عناصر کناریه.

فصل ۳ — فلکس‌باکس و گرید 2 درس
✓ چیدمان با display: flex +

فلکس‌باکس ساده‌ترین راه برای کنار هم چیدن یا وسط‌چین کردن عناصره. با تنظیم display: flex روی والد، بچه‌هاش به‌صورت افقی (یا عمودی) کنار هم می‌شینن.

.container {
  display: flex;
  justify-content: center;
  gap: 16px;
}
✓ چیدمان با CSS Grid +

گرید برای چیدمان دو‌بعدی (هم سطر هم ستون) قدرتمندتره؛ برای صفحاتی مثل کارت‌های محصول یا گالری عکس خیلی مناسبه.

فصل ۴ — رنگ‌ها، فونت و رسپانسیو 2 درس
✓ واحدهای اندازه: px، %، rem +

px یه واحد ثابته، % نسبت به والد حساب می‌شه، و rem نسبت به سایز فونت پایه‌ی صفحه‌ست. برای طراحی رسپانسیو معمولاً rem و % بهتر از px عمل می‌کنن.

✓ طراحی رسپانسیو با Media Query +

با media query می‌تونی استایل متفاوتی برای سایزهای مختلف صفحه (موبایل، تبلت، دسکتاپ) تعریف کنی.

@media (max-width: 600px) {
  .card { flex-direction: column; }
}
فصل ۵ — انیمیشن و ترنزیشن 1 درس
✓ transition برای حرکت نرم +

transition باعث می‌شه تغییر یه ویژگی (مثل رنگ یا اندازه) به‌جای پرش ناگهانی، به‌آرومی اتفاق بیفته — دقیقاً همون افکتی که روی دکمه‌های همین سایت می‌بینی.

.btn {
  transition: transform 0.3s ease;
}
.btn:hover {
  transform: scale(1.05);
}

جاوااسکریپت از صفر رایگان

صفحه‌ی خودت رو زنده کن: متغیر، تابع، DOM و رویدادها.

فصل ۱ — مقدمات و متغیرها 2 درس
✓ let، const و var +

برای تعریف متغیر امروزه از let (قابل تغییر) و const (ثابت) استفاده می‌شه؛ var قدیمیه و بهتره ازش استفاده نکنی.

⚡ JavaScript
✓ انواع داده در جاوااسکریپت +

رایج‌ترین نوع‌ها: string (متن)، number (عدد)، boolean (درست/غلط)، array (آرایه) و object (شیء) هستن.

فصل ۲ — توابع و شرط 2 درس
✓ تعریف تابع +

تابع رو می‌شه به چند شکل نوشت؛ رایج‌ترین حالت امروزی arrow function هست:

⚡ JavaScript
✓ شرط if و ternary +

مثل پایتون، if/else شرط رو بررسی می‌کنه. برای شرط‌های کوتاه هم از عملگر سه‌تایی (?:) استفاده می‌شه.

⚡ JavaScript
فصل ۳ — DOM و رویدادها 2 درس
✓ انتخاب عنصر با querySelector +

برای دسترسی به یه عنصر HTML از جاوااسکریپت، از document.querySelector استفاده می‌کنیم:

const btn = document.querySelector('#myButton');
✓ گوش دادن به رویدادها +

با addEventListener می‌تونی مشخص کنی وقتی کاربر کاری کرد (مثل کلیک) چه اتفاقی بیفته:

btn.addEventListener('click', () => {
  alert('کلیک شد!');
});
فصل ۴ — آرایه و متد‌های پرکاربرد 1 درس
✓ کار با آرایه‌ها +

آرایه یه لیست مرتب از مقادیره. متد‌های map، filter و forEach از پرکاربردترین ابزارها برای کار با آرایه هستن.

⚡ JavaScript
فصل ۵ — فراخوانی API با fetch 1 درس
✓ گرفتن داده از یه سرور با fetch +

fetch رایج‌ترین روش امروزی برای درخواست دادن به یه API و گرفتن جواب (مثلاً برای پر کردن یه فرم یا نمایش داده‌ی زنده) است.

fetch('https://api.example.com/data')
  .then(res => res.json())
  .then(data => console.log(data));
